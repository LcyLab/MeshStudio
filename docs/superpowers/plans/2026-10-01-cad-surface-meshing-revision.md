# CAD 表面三角网格研究与修订方案

> 后续执行使用 `superpowers:executing-plans`，逐项核对验收结果。当前仅研究和制定方案；按用户要求暂停算法实现，不创建分支/worktree，不提交。

**目标：** 自研能够保留 CAD 拓扑、共享棱与面标签的表面三角网格核心，先通过真实复杂曲面的验收，再继续产品交付。

**架构：** OCC 适配几何查询；纯 C++ 核心管理共享边界、参数图表、CDT 与细化；Qt/VTK 处理设置、显示和存储。三维尺寸场、几何契约和诊断接口可供未来体网格复用。

**技术：** C++、现有二维网格基础、OCC、Qt、VTK；本方案不引入外部网格生成器作为生产算法。

## 3. 修订后的方法选择

仍选择 **参数域 CDT＋三维判据自适应细化**，按下面的完整流程实现：

1. 验证几何/拓扑和参数对应关系。
2. 全局共享棱注册与离散，综合所有 incident face 的要求。
3. 形成有效的裁剪图表，显式管理孔、周期缝、退化边和人工切分边。
4. 在规则图表内构造可靠 CDT 和域标记。
5. 使用局部尺寸/度量提出细化候选，先处理边界，再处理面内部。
6. 映射三维后复核；通过全部硬判据才返回成功。

“在 UV 中做 CDT”与“三维网格质量好”是两个需要分别验证的条件。一般变度量下不能对每次翻边任意更换度量，并继续引用固定欧氏 CDT 的终止结论。

### 3.1 参数域与局部度量

定义曲面一阶导数矩阵 `J=[S_u,S_v]`，三维各向同性尺寸映射为：

`M(u,v) = J(u,v)^T J(u,v) / h(S(u,v))^2`。

- 在边端点、中点、候选点和三角形内部查询局部度量；尺寸判据用三维实际弦长和曲面采样复核。
- CDT 的拓扑符号判定保持可靠、确定。第一步先验证普通 UV CDT 的完整性；规则图表可使用固定的正定线性预调节坐标构造 CDT。
- 局部度量负责候选位置、归一化长度与图表失真检测。固定预调节只在相应规则图表内有效，不能用整张 CAD 面中心的一个矩阵代表全曲面。
- 失真大、度量失去秩或跨周期时先切分图表；人工切分边同样登记共享节点。第一版不直接实现缺乏独立验证的任意变度量 incircle。
- 奇异点采用显式的边界等价节点/极点邻域处理；法向返回“有效、奇异、查询失败”状态，零向量不能默认为判据已通过。不能形成有效局部图表时返回具体诊断。

图表有效性是采样验证加拓扑检查，首版不声称证明全域映射单射。严重失真图表必须通过真实用例才能扩大支持范围。

### 3.2 共享边界与细化调度

- 每个 CAD 顶点/棱有稳定 ID；边样本记录 CAD 参数、三维节点 ID；每个 edge use 保留自己的面 ID、分支和 UV。人工图表边另设来源类型，不能冒充 CAD 棱。
- OCC 适配层核对 `edgePoint(t)` 与各 `facePoint(edgeUV(t))` 的残差及允许容差；不能假设所有 p-curve 都与三维曲线同参数且精确一致。
- 曲线采样在连续区间进行；跨 B 样条导数连续性断点、周期端点和奇异点时分段检查。法向变化比较同一张面的同侧连续采样，CAD 硬棱两侧法向跳变不作为沿棱无限细化要求。
- 两类工作队列：边界缺陷/侵入队列优先，面内部坏三角形队列其次；用版本号淘汰失效队列项，只更新受影响邻域。
- 插点采用外心基线；候选在域外、侵入约束或过近时先处理相关边界。CAD 棱按曲线参数/弧长求分裂点，然后同步每个 incident face；不能把 UV 线段中点直接当作公共 CAD 棱节点。
- 对规则图表增设依据局部尺寸的 off-center/前沿候选，必须与外心基线分别比较；首轮先把外心和保护逻辑做正确，随后接入候选策略。
- 侵入约束需要按算法规则处理；当前“只有边本身已违反尺寸/误差才分裂”的条件不能视为标准 Delaunay 细化。受尖角保护阻止分裂时，应拒绝该质量候选并报告局部冲突。
- 共享棱分裂只使关联面失效。先允许重建这些面；增量 CDT 稳定后再局部更新，避免每次重算整个模型。
- 插点/分裂/翻边失败必须恢复原拓扑。检测重复候选、无几何进展和失效队列循环，失败诊断保留 face/edge、参数区间和判据值。

### 3.3 尖角、窄区与相交

- 根据 CAD 拓扑和局部距离建立特征约束；UV 中的窄区与三维中相近但拓扑不相邻的曲面分别检查。
- 尖角采用保护邻域/分层分裂思想，保留强制边界角；例外应有明确位置和几何原因，不能把全部边界三角形排除出质量检查。
- 先检测边界离散是否产生额外交叉，必要时局部加采样。三维邻近曲面通过空间索引筛查；操作前后检查相关三角形，最终再全局检查。
- 有限采样与容差相交检查只能给出测得结果。严格无交保证需要另一个阶段实现并验证曲面子片的保守包围/区域分离，不能用普通 AABB 筛选冒充论文的临界区域证明。

## 4. 参数与 API 保持一致

| 参数 | 设置 | 修订后的明确语义 |
| --- | --- | --- |
| `h_target` | 可调；自动值 `0.025 × 包围盒对角线` | 三维目标尺寸。现有 5% 边长余量必须明示并纳入测试，不能称为精确最大边长 |
| `h_min` | 可调；自动值 `0.1 × h_target` | 常规加密下限；几何/必保特征需要更小时记录来源与实际尺寸；阻止满足硬条件则失败 |
| `δ` | 可调；自动值 `0.1 × h_target` | 映射误差的自适应采样限值；另用独立 CAD 点到网格和网格到 CAD 距离验证，区分测量定义 |
| `θ` | 可调；默认 30° | 同一连续曲面区域的最大采样法向变化；奇异点状态单独报告 |
| `ρ` | 内部默认 `√2` | 三维外接圆半径/最短边的质量目标；平面终止理论使用的二维指标单独记录，不能混为一谈 |
| `g` | 内部默认 1.3 | 目标尺寸渐变控制；在已建立的邻接采样图上限制相邻目标值比例并报告最大比例，有限图检查不等于连续空间上界 |
| 工作/节点上限 | 显式护栏 | 分别记录采样、插点、翻边、面重建等次数；预算耗尽包含具体未满足条件 |

长度使用导入几何坐标单位；未确认单位时显示“模型单位”。

公共 API 保留 `GeometrySource`、`MeshSizeField`、进度/取消、`SurfaceMesh3D` 及标签；补几何容差、参数周期/连续区间和查询状态时放在适配契约中。三维尺寸场保持独立于 UV 和 OCC。

表面独有的图表/CDT/细化位于表面模块；未来 `VolumeCriteria` 与四面体算法独立。未来体模块接收已共享节点的表面结果、面/棱归属和方向，不重新容差焊接；此次不新增该入口。
