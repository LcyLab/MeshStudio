### 已实现

- 输入处理：OCC 严格适配默认不修复；实际表面引擎在深复制的内存形状上尝试有界的共享端点容差协调。phone 仅改顶点 434/433 的容差为 2.70924906199e-5 / 2.70965129642e-5；曲线、曲面、坐标、拓扑和标签顺序不变，完整 B-Rep 检查通过才接受。真实内部裁剪交叉的负例仍拒绝，原 STEP 不变。
- 表面语义：纯 C++ API 新增显式 `AssemblySurfacePolicy`。默认 `RejectBodyOverlap` 保留严格兼容入口；GUI 引擎、诊断及基准工具使用 `IndependentBodies`。同一部件的自交仍拒绝；不同实体各保留完整表面。跨部件网格交叉按 CAD 接触、体积干涉、无测得接触或查询失败记录，不将查询失败当作无干涉。
- 元数据：每片 `CadBodyId`；字段数据 `CadAssemblyPolicy` 和 `CadBodyInteractions`。后者每行五个 int：部件 A/B、CAD 面 A/B、关系类型（0=无测得 CAD 接触，1=边界接触，2=公共体积干涉，3=查询失败）。这来自网格相交候选，不是装配体所有实体对的完整干涉审计。容差协调发生时同时保存 `CadAcceptedBRep` 和 `CadInputReconciliation`；工程原文件继续保留原字节。
- 凹球质量：几何细化收敛之后，用三维半径边比驱动非约束翻边及内部节点移动；移动候选包含邻点 UV 均值及局部切平面度量映回 UV 的位移。所有共享棱/缝/极点节点固定，逐候选检查域、方向、尺寸、偏差和法向。最终重新验收闭合及相交，失败回滚到已接受的几何网格。质量为软目标，剩余工作预算不足时报告残留，不影响此前硬判据的收敛。
- 矩形初始化：只从相应水平/竖直边取 U/V 切分；每格使用两片而非额外中心点，避免微小 p-curve 横向漂移造成网格乘积膨胀。重建废弃的内部节点槽复用，CAD 公共节点编号稳定。

详细检查只找到 face 288（零基，即第 289 面）的 `UnorientableShape` 和其 wire 的 `SelfIntersectingWire`。
该面为平面，相关 CAD edge 657/665 共享同一顶点。裁剪曲线独立求交得到一个约 2.25e-8 长度的相交/重合段，位置 UV 约 (4.6725563,-4.9946129)。它距共同端点约 2.46e-5 个模型单位，共同顶点容差约 7.34e-7。

源码根因：

- `CadSurfaceMesher.cpp` 在面中心求一次 `FaceMetric`，整面 CDT/翻边一直用它。球面极点附近 du 的物理尺度收缩，中心度量不能代表该处。
- 硬尺寸/法向条件主要二分边，其他分支使用 UV 重心插点；未按局部度量用质量候选修复瘦长片。
- `qualityViolation` 跳过任一边界节点，以及最短边 ≤2min 的所有面片。极点内部的过短边因此直接停止质量细化。
- 最终笼统说“quality target limited by constrained features or minSize”，没有证明坏片受不可避免的几何限制。

只读换边候选探针：961 对非约束内部邻接片，在 UV 凸性和新边最大尺寸检查下存在使局部最坏 R/最短边下降至少 20% 的替换，涉及 1517 个坏片。探针没有实际修改网格；候选相互重叠，也未检查全部几何误差/相交，不能当成优化后的验收结果。

独立有限距离采样通过：1183 个 CAD→面片样点（含 787 内部点）、384 个面片→OCC 样点，最大距离 1.955742/0.426718，小于 δ。不能证明全局误差上界。
真实 Qt/VTK 测试通过生成、最大边、取消、保存重开和标签参数恢复；已查看图像，极点附近片形仍明显不均匀。通过这些检查不代表质量问题解决。

## 待确认的实施方案

### A. 凹球质量（核心行为调整，先确认方案）

1. **反例先行**：在 `CadSurfaceMesherTest.cpp` / OCC 测试增加带极点的球面反例，统计内部/边界未达标片、极小角和尺寸；不能仅验证 generate.ok。固定默认参数，不依赖放宽质量值。
2. **局部度量与候选**：在 `SurfaceChart` 和 `CadSurfaceMesher` 中依据待处理邻域求切平面度量。保留 UV CDT 作为约束拓扑起点；几何畸变区域的质量处理使用局部度量和三维测量。普通几何细化与质量细化分开选择候选，质量分支不再无条件插 UV 重心。候选需在有效裁剪域内；极点奇异度量要明确选择非奇异邻域或局部图表，不能随意添加 epsilon。
3. **不增点的质量改善**：先复用 `Mesh2D` 局部事务做非约束换边与内部节点受限移动，固定共享 CAD 棱节点和逐面 UV。短边不再禁止换边/移动；min 只限制常规加点。每次候选检查三维方向、最大边长、法向/偏差采样、局部域、邻接与质量下降；失败回滚。不能在最后再用旧中心度量把已经验证的质量改善翻回去。
4. **必要时局部图表**：若在有效邻域内无法处理极点畸变，增加极点局部图表，图表接缝共享节点；不重新焊接 CAD 共享棱。此步可能扩大实现范围，届时给最小反例和结果，再确认具体设计。
5. **准确报告**：逐面统计质量残留，标明位置和“边界/最小尺寸规则跳过/候选无可接受改善”等真实退出原因。不可改名为“特征必然限制”，不可只改善最差值而隐藏大量坏片。
6. **验收**：同一默认参数、同一原凹球，报告改善前后数量、最小角及分位数；要求当前已找到可改善的内部瘦长片得到明显改善。局部失败必须有原因。完整闭合/方向/约束/相交检查、独立距离采样、真实 GUI 保存重开通过；再跑现有 move/ball 及默认回归，记录新耗时。
