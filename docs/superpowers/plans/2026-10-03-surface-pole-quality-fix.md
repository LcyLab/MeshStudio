# 凹球极点及裁剪边质量修正

日期：2026-10-03。用户已批准继续修复。最终 Release 全构建和 33/33 相关回归通过；原凹球默认参数独立质量严格通过（0 超标），两原模型三轮对照、全部 CAD 面独立审计及实际 GUI 验证通过。本轮不改四面体算法、Dialog 参数或原 STEP。

## 根因证据与实现范围

原最差片 triangle 2667 / face 0 含北极 `(0,0,500)`，最短边 7.35592 大于 min=4.33013，不是被尺寸下限直接排除。UV 中心与拒绝日志对应，原线性候选 U=3.26569 越过半球 U=π。物理切平面候选也可能真正在裁剪域外：只换参数表示不能解决全部问题。

- 新 `SurfaceTangentChart` 从实际三维邻域建立局部切平面。使用已有 CAD 坐标/D1 查询、有界 Newton 和缩步反解回原 UV 窗口；检查法向同侧、残差和迭代上限。保持纯 C++，未增加 OCC/Qt/VTK 依赖或 GeometrySource 纯虚方法。它不是全局最近点投影，窗口也不是裁剪域。
- 有退化棱的面在后置质量候选中补切平面候选；原有效域、约束、事务及三维验收继续负责接受/拒绝。反解失败有具体诊断，不夹回边界、不删除特征。原 UV 拓扑仍保留，尚未完成任意极点补丁的独立图表重剖分。
- 若实际极点邻域已有差片，协调与极点相邻的共享棱，保留统一节点 ID；使用真实 CAD 参数中点，并检查两侧物理子段不小于 min。候选越界的这类极点扇形可通过边界布局改善。
- `qualityBoundarySplitAllowed` 检查普通边界段被对顶点侵入，且中点两子片不恶化最差形状、改善质量总和，并保留父片/所有新增边的最小尺寸。共享棱分裂仍由现有队列统一执行。
- 增加几何完成后的共享棱反馈。节点池压缩推迟到全部反馈结束；未失效面保存已优化连接、UV 和测量，避免回到旧缓存。只重建关联面。
- 确有后置共享棱试验时保留一份已验收网格，计入观察器整网格复制统计。重建后的最差质量或超标数量恶化、或者没有改善时，返回原已验收网格并记录试验值/回退；回退后不继续复用试验图表。预算、取消与硬条件失败仍明确返回失败。这项保留会增加内存和耗时，不能称零开销。
- 后置有限物理形状移动只在原生成/优化完成后运行，固定边界，比较整个节点星的最差值和总和。重剖分后再优化新邻域。min 限制质量新插点/新边，不禁止已有硬几何细化节点的移动，避免重现上一阶段把凹球恶化到 195 片的错误约束。
- 新 `SurfaceLocalRemesh` 在完整内部一环中移除普通内部点的连接，最多 16 邻点、四轮调度。可靠 UV 判定检查新对角线在同一简单多边形内、不占用补丁外连接；动态规划在全部合法剖分中选择最小最差三维成本。成本必须改善原补丁最差质量并满足几何/尺寸；CAD 原顶点、约束端点和同面多 UV 共用三维节点均保护。局部拓扑/域事务拒绝或异常回滚；原点槽/UV 索引保留，最后仅压缩无引用三维节点。这是有界内部点一环重剖分，未实现一般内部边收缩或任意大型空腔重网格。
- 实测多数 phone 局部尝试被拒绝且每次整面扫描入射片，补当前版本节点邻接索引：失败复用，成功压缩三角形槽后重建。核心检查索引完整闭合、重复、过期和节点归属；缺少索引时保持原扫描入口，单元测试比较两入口结果及拒绝后未修改。提前按质量跳过 CAD 查询的试验已撤回，最终仅保留索引复用；跨版本完整指纹发生变化，不宣称逐字节等价，最终版本须单独通过模型质量/几何/GUI 验收。

## 先失败、后修复的验证

- 实际极点 UV 的原候选越界回归先失败。随后发现要求“切平面必定给出域内候选”本身不成立，改为验证原 UV 同分支反解和诚实拒绝域外点；没有放宽生产裁剪条件。新增单位变换、UV 拉伸/平移分支、奇异 D1、非有限输入和 CAD 异常传播覆盖。
- 增加原模型独立质量断言。关闭本次极点协调路径，冻结默认参数后，worst=2.03794、minAngle=14.2023°、bad=15，超过回归上限 1.8；恢复路径后通过，worst=1.72906。1.8 是防止此缺陷复发的测试上限，生产质量目标仍为 √2。
- 普通边界判据先用缺失实现复现失败，再补尺度、最小尺寸、恶化子片、等边/非侵入和实际球面裁剪弧检查。
- 单点移动初轮只少一片，未降低当时最差值；局部重剖分接入后，独立 worst=1.42325、bad=1，1.6 断言通过，但严格 √2 断言明确失败。重剖分后优化、已有短边节点的有界形状移动接入后，worst=1.41406、minAngle=20.7072°、bad=0，严格 √2 断言通过。
- 新局部重网格测试先失败，补凸/凹邻域、约束保护、无有效剖分、点槽/参数索引保持和最终验收 veto/异常后的三角形、邻接、版本、域标签恢复；33/33 相关回归通过。

## 保留的失败试验

1. 等边顶点移动使最差值升到 2.10525，已移除该接入。
2. 首次原模型回归参数赋值位置错误，实际 max/min 未按命令目标覆盖；修正顺序后才取得有效的 2.03794 失败对照，错误参数输出不作验收。
3. 放宽边界预估为只降低质量总和，一次重建使最差值升到 2.6062。已恢复“不恶化最差子片”的预估，并补重建后验收回退。保护版本实测将这一试验拒绝，输出保持已验收的 1.72906 网格。
4. 反解和单片预估不能证明后续整面重建一定改善；上述失败是增加最终验收的依据。无效方案和运行目录均保留，未用增大预算、放宽几何偏差或修改原 CAD 掩盖。
5. 接入内部重剖分但尚未复用索引的版本，三轮 phone 核心中位数 29.9436 秒、凹球 1.1023 秒。索引复用前后独立质量统计、工作统计相同，但完整指纹变化；手机部分关系记录的代表 CAD 面改变，未删除部件或关系。差异没有被称作完全一致，正式六轮以最终代码重新记录。
