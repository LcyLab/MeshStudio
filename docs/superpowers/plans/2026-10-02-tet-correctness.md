# 四面体正确性与表面入口

用户批准上一轮方案后实施；自研算法、原工作区、无分支/worktree/提交。

## 实施边界

1. 先修质量计算和成功语义，不扩大阈值让坏单元通过；生成的可诊断结果和验收通过单独表示。
2. 将现有浮点展开回退扩展到 3D，精确零才允许符号决胜。
3. 闭合体边界采用独立验收模块，保留原表面允许开放壳的行为。
4. 面覆盖按实际共面三角面片交叠面积验收，而不是“另外两边存在”推断；合格面构成域分类屏障。先用现有翻转能力恢复面，不能恢复的构型明确失败。受预算保护，不作无限细分或丢弃约束。
5. 沿四面体邻接跨屏障奇偶分类，剔除外域和内腔；细化/平滑后再次验证边界和体积。
6. UI 使用选中表面网格的原节点/CAD标签快照，CAD 输入自动调用自研表面核心。来源、转换和标签须可检验。

## 验证

先写真实失败用例再改实现：gamma/二面角、假收敛、3D谓词近退化、体边界流形、自交、面覆盖与凹体/空腔分类、保存恢复及 CAD→自研表面→体入口。构建由主代理串行统一进行。

## 最新实施边界与结果（2026-10-02）

用户要求先不改三角面片代码，另一个进程正在修改它。后续冻结自研表面生成、表面 UI 和 CAD→表面集成验证，改用 Gmsh 固定 T3 面网格；生产四面体核心仍为自研，Gmsh 只作为测试输入来源。此前已写入的表面选择快照/自动入口暂保留，最终产品 GUI 验收延期，不根据早期测试宣称最新集成已通过。

已实现：

- 真正的 gamma、六个内二面角、最大边长/半径边比及薄片统计；细化最终全局检查，停滞/跳过/未解决单元不能假收敛。生成成功与 `qualityAccepted` 分开，平滑拒绝恶化局部质量的移动。
- 3D filtered/exact 浮点展开谓词，精确零时使用一致全局节点编号决胜。修复分离双体插点定位：原零体积单元可被错误判定为包含任意点。清理仅删除精确零体积单元，薄正体积单元保留并报告质量问题。
- 独立体边界验收（有限坐标、索引、重复、退化、闭合方向、顶点流形、自交及壳体）；索引输入不焊接，拒绝会改变编号的重复坐标。共面面积覆盖双向检查、有保护和预算的 2→3/3→2 面恢复、邻接跨边界屏障奇偶域提取；细化/平滑后复验边界与体积。
- 网格校验拒绝共享面同侧的重叠四面体。来源面/棱标签、分片角点 UV 通过覆盖映射保留；UV 为输入面片上的插值，不等于重新投影 CAD。工程保存质量状态，旧工程不凭缺失字段伪造验收通过。

精确谓词依赖正常 IEEE 浮点环境和中间量可表示；不是任意指数范围的保证。相交与共面覆盖仍有容差，签名壳体体积不是多壳材料奇偶体积。当前面恢复不是通用 PLC 空腔重建或 Steiner 面恢复。

## Gmsh 独立输入验收

`tests/GmshTetFixtures.py` 使用本机已有 Gmsh 4.13.1，仅 `generate(2)`，算法 6、单线程、线性三角形；分别 h=1、0.5。使用官方 [`setOutwardOrientation`](https://gmsh.info/doc/texinfo/#gmsh_002fmodel_002fmesh_002fsetOutwardOrientation) 定向实体边界，避免把几何面的自然方向当实体外向。导出保留 Gmsh 坐标/面连接/标签，压缩使用节点编号，不几何焊接；冻结输入与生成来源在 `test_data/gmsh-tet/`。

测试路径为固定 Gmsh T3 → `TetMeshEngine`，不调用 `SurfaceMeshEngine` 或 `CadSurfaceMesher`。独立检查四面体行列式体积、凹区/空腔/分离间隙探针、面覆盖、方向及源棱区间覆盖；探针仅是额外验证，不参与域分类。体目标尺寸统一 3，半径边比目标 2，质量还要求无退化单元、无内二面角小于 5° 的薄片。

## 实际验证与复现

Release 的 13 个体相关/存储测试目标构建成功。最终选定 23 项 CTest 全通过，包含 10 项 Gmsh 固定输入测试；粗球面是预期明确拒绝的负例，细面网格中的质量失败也必须如实报告。未跑正在由另一进程修改的三角面片回归，未在最后四面体改动后重跑产品 GUI。

```powershell
ctest --test-dir build -C Release --output-on-failure -j 4 -R '^(Delaunay3DTest|GeomPredicates3DTest|VolumeBoundaryValidationTest|VolumeDomain3DTest|Constrained3DTest|Ruppert3DTest|Flips3DTest|Smooth3DTest|TetQualityAcceptanceTest|VolumePipelineTest|TetMeshEngineTest_(cube|cube10)|ProjectArchiveTest|GmshTet.*)$'
```

每个 Gmsh 用例的真实报告在 `build/GmshTet*.json`，成功结果同名 `.vtu/.vtp`。例如 `build/GmshTetPipelineTest_cavity_h0.5.json` 保留体积、薄片数量及质量告警；负例 `build/GmshTetBoundaryRejection_sphere_h1.json` 保留未恢复面诊断。运行回归不要求安装 Python/Gmsh，只在重新生成固定输入时使用它们。未创建分支/worktree，未提交。

当前未完成的算法能力：更一般的约束面恢复与薄片消除。后续四面体工作应继续复用固定 Gmsh 输入定位这些问题；自研表面集成等待另一进程稳定后单独验收。
