# phone / 凹球表面三角网格修正方案

> 状态：用户已确认，A–C 首轮及 D/E 有界范围已实施：切平面候选/原 UV 反解、共享棱质量反馈和内部一环重剖分；原凹球默认质量已达标。phone 全面质量、任意极点拓扑图表和一般内部边收缩尚未完成。最新验收见 `2026-10-03-surface-pole-quality-fix.md`；A–C 历史见 `2026-10-03-surface-quality-stage-abc.md`。实施在当前工作区逐项执行，使用 `superpowers:executing-plans`；不创建分支/worktree、不提交、不自动分派子代理。

**Goal:** 保留独立 CAD 部件及真实特征，在默认参数下稳定生成 phone / 凹球表面，提高三维三角形质量，并使残差、几何误差与耗时可复核。

**Architecture:** 保留 OCC 几何适配和纯 C++ 的 UV CDT 主流程，复用共享边登记、局部事务、域标签、版本队列和查询缓存。新增能力按边界尺寸、质量保护、候选生成和局部重网格分开；通过现有三维判据及最终验收统一决定是否接受。

**Tech Stack:** 当前 C++/CMake/CTest，OCC 仅负责 CAD 查询，现有 Qt/VTK 展示与保存。

## 约定与边界

- 保留用户确认的 `IndependentBodies`：各部件完整生成，接触和干涉有标记；同部件自交仍拒绝，不做布尔合并/切割，不构造多区域公共接口。
- 目标/最小/最大尺寸、几何偏差、法向角的现有入口及模型坐标单位继续有效。最小尺寸是常规目标下限；保留真实更小特征及硬几何要求时才允许突破，并记录位置/原因。质量目标本身不自动突破最小尺寸。
- 几何、方向、闭合、约束与同体相交是硬条件；质量目标仍有明确的局部例外。硬条件失败返回失败，不能只写警告然后交付成功网格。
- 继续自研算法。借鉴已核对源码中的机制，不把 Gmsh/Netgen 作为生产生成器。
- 当前四面体代码由其他任务维护；本方案只使用共同契约，不修改四面体算法或其接入状态。UI 布局保持已有 Dialog，初轮不增加高级参数。
- 所有阶段保持默认工作/节点预算，先通过可复现例子再跑原模型；不靠增加预算、放宽硬条件或删除 CAD 特征使结果通过。

## 方案选择

1. **推荐：补生成过程的尺寸与候选机制，然后扩展局部优化。** 可沿用当前数据结构，逐阶段看出质量改善来自哪里，风险局限在表面流程。
2. **只增加平滑轮次。** 改动小，但无法解决边界尺寸不匹配、错误的内部点分布或极点参数退化，不作为主修正。
3. **整体重写为新前沿生成器。** 范围大，会重复实现共享边、裁剪孔、回滚和验收。本轮不选。

## 现状与根因假设

已确认的实现限制：

- `CadSurfaceMesher.cpp:1171–1173` 质量细化排除所有贴边片及最短边不超过 `2*h_min` 的片；范围过宽，但不能仅删除判断，否则可能触发尖角无界加密。
- `1085–1089` 主 CDT 使用 UV 包围盒中心的固定度量；普通细化候选取 UV 重心。局部 D1、曲率估计与物理移动能力已存在，尚未完整进入候选构造。
- 共享边节点固定、短 CAD 段长未传播成面内部的局部尺寸过渡带；后处理只有换边和内部节点移动。
- 现有缝/极点 UV 分支处理尚未形成可切换局部图表，内部短边不可收缩。

前轮记录：phone 112066 片，15290 片超过半径边比目标；13858 片触及固定裁剪，14531 片最短边不超过 `2*h_min`，两组重叠。凹球 13938 片，超标片 3040→23，最小角约 14.20°。这是已有运行记录，本轮未复跑，不能从这些数值推出全部坏片的原因。

验证假设的方式：先输出每个残差片的三维形状、CAD 面/棱、边界邻接、角度、局部尺寸与映射条件，再用小例子分别隔离短边过渡、尖角、极点和参数畸变。对原模型按同一组参数逐阶段比较。

## 实施阶段

### A. 固定基线和残差定位

- [ ] 复用 `CadSurfaceQualityAuditTest` 的独立测量，增加三维最小角、半径边比的 p95/p99/最大值、超标数量与每部件统计；细化片数量变化时同时比较数量和比例。
- [ ] 保存完整残差 CSV/VTP：片号、CAD 部件/面/棱、三角形三个坐标、最短边、质量值、边界情况、局部尺寸、预算/候选拒绝原因。生成器内统计有界，完整导出放在审计工具，避免额外大常驻数据。
- [ ] 增加短边接大内部片、真实尖角、UV 拉伸、球面极点的隔离例子，先确认现有缺陷或未达到的新要求。
- [ ] 用观察器记录导入/适配、共享边、逐面生成、物理优化、同体验收、跨体关系查询的耗时；观察开关不得改变结果。

完成条件：所有超标片可追溯，原因未证实时标记未知；确定下一阶段优先处理的 CAD 面/棱，不把“贴边”当作不可改善的原因。

### B. 边界尺寸过渡和明确的质量保护

- [ ] 从共享边当前节点链读取实际三维段长，形成逐面尺寸种子；短段/窄区与尖角由局部拓扑、相邻边方向及距离证据标记。
- [ ] 尺寸传播只沿同一面有效网格邻接，不越过孔、裁剪边或不同部件；初始种子建立后，每次插点/换边局部更新，避免每片重新扫所有 CAD 边。
- [ ] 按渐变率 1.3 限制相邻目标尺寸突变。普通尺寸不小于 `h_min`；真实小特征与硬几何需要更小时给出单独标记，质量候选不因此获得无限分裂许可。
- [ ] 将“任意贴边/短边跳过”替换成明确策略：普通边界可细化；尖角保护、最小尺寸冲突、无有效候选、预算耗尽分别给出原因。约束侵入先请求共享边同步切分；受保护区或切分低于允许尺寸时拒绝该候选。
- [ ] 共享边版本更新只使相邻面和对应尺寸种子失效；在有界队列内处理，沿用节点 ID。

完成条件：短边隔离例子的质量改善、真实尖角不无限加密；孔/跨体不传播；共享边一致；没有静默删除小特征或修改 `h_min`。

尺寸组合规则：普通点 `h(x)=min(h_user(x),h_curvature(x),h_boundary(x),h_max)`，其中普通边界过渡不低于 `h_min`；证实需要保留的更小特征/硬几何区域单独标记允许尺寸。实施中尺寸传播修订为 `h_j <= h_i+(g-1)*distance_3d(i,j)`（双向，`g=1.3`），沿有效域邻接传播，并在插入新增合法邻接时恢复局部过渡。原因：粗 CDT 的一条长边不应将很小的尺寸以固定倍数立即传播到远处；尺寸源固定为首次几何采样，质量细分不新增更小源。原 CAD 边的参数中点不一定是三维等分点，质量切分还检查两侧实际三维长度，不能只比较父段长度。以上是局部布点启发，不宣称全域或测地线尺寸上界；实际边长与几何采样仍决定是否接受。

### C. 局部度量中的候选布点

- [ ] 复用 `surfaceMetricAt()`，在坏片及其邻域取曲面 D1，检查正定性/尺度及映射畸变；每次空腔或换边事务固定同一局部度量和稳定决胜。
- [ ] 对普通质量缺陷按“局部度量外心→沿有效邻边的偏心点”尝试；硬几何缺陷允许原重心/内部边二分候选；每次尝试有限，不进行无界位置搜索。
- [ ] 候选依次检查：有限/可表示、不重合、有效裁剪域、约束侵入、局部拓扑，再检查映回三维后的尺寸、偏差、法向和翻折。
- [ ] 复用 `Mesh2DTransaction`、`SurfaceDomainState`、`SurfaceRefinementQueue`；只更新编辑邻域。候选失败回滚，拒绝原因进入残差统计。
- [ ] 初始 CDT 仍作为拓扑种子；局部重连/布点逐步消除整面中心度量对三维质量的支配，不把所有 incircle 简单改成各自不同的度量。

完成条件：同一物理面的 UV 拉伸/剪切例子质量接近；没有换边循环；候选接受后硬判据仍成立，原共享边和面标签无损。

### D. 极点和周期缝专门处理

- [ ] 在适配层明确退化边、周期分支及三维节点对应；保留一个三维节点对应多个 UV 的现有结果表示。
- [ ] 极点附近插点不平均无定义参数，使用有效方向和相邻规则；无法建立正定 UV 度量时构造局部切平面图表。
- [ ] 局部图表内的候选通过受裁剪域和分支约束的 CAD 投影返回原 UV；不能只投到无限延伸的底层曲面或任意周期分支。
- [ ] 图表边界、约束映射、回投残差及三维翻折全部检查；转换失败返回具体面/极点诊断，有限尝试后停止。

完成条件：球极点、圆柱周期缝、带孔球面裁剪例子没有重复三维节点、裂缝或反向片；凹球残差须逐片归因，不能笼统称“极点导致”。

接口补充仅在本阶段需要时加入 `GeometrySource`：受 UV 种子/参数窗口约束的面投影查询和周期信息查询，默认返回“能力不可用”，不用新增纯虚函数强制所有已有/体网格适配器改动。投影结果包含原 CAD UV、三维点、残差、裁剪域及分支状态；算法核心只依赖数值类型，OCC 执行投影。没有投影能力时，规则 UV 路径仍可运行；需要备用图表而能力缺失时明确失败。

### E. 受保护内部边收缩与局部重网格

- [ ] 仅在 B–D 后仍存在可定位内部点簇/短边时启用本阶段；不删除 CAD 顶点、共享边节点、周期对应及受保护点。
- [ ] 收缩前验证三角网格 link condition、一环域标签及约束，不跨 CAD 面/部件；新点映回原 CAD 面并保留角点 UV。
- [ ] 扩展事务覆盖点坐标、精确 UV 索引、半边、拓扑/尺寸版本、全局节点引用与队列，不用只恢复三角形的旧事务冒充完整回滚。
- [ ] 收缩必须改善局部三维质量或尺寸分布，并通过硬判据；取消/验证失败恢复所有状态；最终压缩保持标签/边界引用一致。

完成条件：故障/取消后状态等价、边界链完全不变；同体闭合/自交及独立双向采样通过。未通过时保留 B–D 已验收结果，报告仍存在的残差。

### F. 装配诊断、原模型与交付验收

- [ ] 同体自交检查完成后，对跨体网格相交候选去重，单独记录 OCC 接触/体积干涉查询；每实体对只做一次 Common，每面对距离复用缓存。
- [ ] `IndependentBodies` 不因布尔关系改变各部件表面；查询失败标记 `QueryFailed`，不冒充无干涉。严格模式仍按原语义拒绝未证实的交叠。
- [ ] 跨体候选诊断只对最终结果运行，避免每轮软质量优化重复做相同查询；没有建立全部实体对 CAD 审计时，明确记录覆盖范围。
- [ ] 按固定参数/Release/同机器各跑三轮，分开生成、诊断和独立审计计时；观察开关结果一致，报告三轮范围与中位数。
- [ ] 用原 phone/凹球以及 move/ball 回归，核对共享边、每实体闭合方向、零退化、同体自交、逐 CAD 面独立双向采样、最大边和法向统计。
- [ ] 实际 Qt 入口生成、取消、显示、保存/新窗口重开；坐标/连接/部件、面、棱、UV 与诊断逐值核对；完整 Release 构建及表面相关回归，不把并行四面体任务的状态混报。

完成条件：两原模型默认生成通过、全部硬条件通过，残差有明确位置和原因；普通可改善区域质量通过隔离例子，并在原模型中量化改善。全部未处理区域要报告，不能仅使用平均质量掩盖最差片。

## 验收指标与停止条件

| 项目 | 判定 |
| --- | --- |
| 生成稳定性 | 原模型默认参数与原预算成功；取消或硬几何细化预算耗尽返回失败；软质量阶段耗尽须明确报告残差 |
| phone 部件 | 保留 132 个部件的面覆盖和标签，接触/干涉不丢；不要求新网格点数与基线相同 |
| 几何和拓扑 | 每实体闭合/方向正确、共享约束完整、无退化与同体自交；距离独立采样覆盖所有 CAD 面 |
| 三维质量 | 逐阶段报告坏片数/比例、最小角、半径边比 p95/p99/最大值及残差空间分布；不能保证真实尖角处全达 `√2` |
| 质量完成标准 | 普通、无已证实几何/最小尺寸冲突的区域达到半径边比 `√2`；允许残差须逐片有可复核约束证据。仅标记“候选耗尽/预算耗尽/未知”不算质量修正完成，即使能返回几何有效网格 |
| 改善数量 | A 完成后，根据可改善区域确定 phone 数量目标；目前不编造最终坏片数。凹球争取消除剩余 23 片；若不能，逐片说明几何/尺寸证据和仍缺少的算法能力 |
| 性能 | 原默认配置三轮对比；点片数、阶段耗时、局部工作量及峰值内存同时记录。不预先承诺速度倍数；超过基线中位数 20% 时停下归因再决定取舍，不视为已完成效率目标 |
| 数据完整性 | 原 CAD 文件哈希不变，工程往返保留全部现有标签及诊断；单位不猜 mm |

需要重新让用户决策的情况：只有删除/合并真实 CAD 特征、修改输入几何/拓扑、改变独立部件模式、改变面板参数语义，或明显质量/效率取舍才会改变当前授权边界。普通实现细节不逐步征求确认。

生成成功与质量达标分开统计；新增诊断优先使用结果中的现有 `diagnostics` 和 VTK FieldData，不为这次修正大改工程存档格式。共享 API 保持兼容。
