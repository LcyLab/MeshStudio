# 借鉴 Gmsh 流程、使用自有几何算法库的曲面网格方案

日期：2026-10-06。状态：用户已批准进入实施；本文保留方案，最新实现/证据见同日实施计划与 progress.md。

## 目标和边界

用户最新澄清：orient、incircle、三角剖分和局部拓扑操作等几何算法可以自己写；算法思路、规则和流程可以借鉴 Gmsh。不要求重新发明成熟算法，也不要求本阶段开发完整 CAD 内核。现有 GeometrySource / OccCadGeometry 继续提供 CAD 求值、导数、裁剪域和投影查询。

目标是在相当的网格密度和几何要求下，使大部分自由内部三角形接近等边，整体形状分布接近 Gmsh Algorithm 6；同时保留真实特征、部件边界和调用方指定的材料/边界条件界面。允许跨同一实体内的光滑 CAD 分割边。锐角、窄带、尺寸过渡区单独评估，不承诺每个三角形等边。

本阶段不做并行、四面体接入、UI 重构，也不以创新为前置条件。方案提出时旧实验停在 v4；用户随后批准实施，当前实现与未完成项记录于 progress.md 和实施清单。

## 路线选择

| 路线 | 收益和代价 | 判断 |
|---|---|---|
| 按 Gmsh 算法契约，在自有算法库上实现参考生成器 | 几何谓词、拓扑和数据结构归自己维护；需要逐项验证流程差异 | 推荐，符合最新澄清 |
| 抽取 Gmsh 源码并适配 | 少写部分代码，但耦合 GFace、MVertex、MTri3、BDS 等类型，需要处理许可和维护 | 本方案不采用 |
| 继续在旧生成器中增加局部补救 | 改动起步小，但布点、尺寸、细化相互影响，难定位布局差距 | 作为对照保留 |

推荐主线：**成熟流程参考 → 自有算法内核 → 同条件对照 → 有证据的产品改进**。先建立可解释的参考实现，之后再引入差异策略。

## 为什么这次需要对齐整条生成流程

v4 原模型实验中，phone 近等边比例由约 12% 提升至约 40%，凹球约 33%→32%；已通过的规则面反例不能说明工业模型目标已达到。当前路线借用了前沿思想，但已有多个不同于 Gmsh 的规则，且后续硬细化会重新改变布局。

重新核对固定版本 4.15.2 源码后，必须纳入参考契约的差异包括：

- 活动三角按归一化半径调度；`isActive` 按边索引返回首条满足条件的边，不能笼统理解为“挑最短活动边”。
- 点位度量在三角形 UV 重心求取；目标高度使用活动边两个端点尺寸的均值，并区分边界尺寸传播与背景尺寸。
- 偏心点沿边中点到度量外心方向放置，距离为 `min(sqrt(3)/2*h, 中点到度量外心距离)`，再尝试曲面与物理圆求交修正。
- 普通 CAD 的圆求交失败时，Gmsh 保留初始度量候选；本项目当前反解失败拒绝的行为不同。参考模式需明确此分支，并保留裁剪域、有限值和几何合法性检查，不能静默放行错误点。
- 插点同时检查局部空腔、UV 面积、邻近点距离和边界距离；失败后恢复原拓扑，成功后只更新受影响的邻接及活动集合。

这说明“用了前沿”不足以说明生成策略一致。性能也应测量局部更新、CAD 查询和产品验收的开销，不能用流程数量推断快慢。

## 模块与流程

`CAD 查询 → 边界采样/尺寸场 → 初始约束三角网 → 前沿生成 → 有界优化 → 原 CAD/拓扑验收`

| 模块 | 自己实现或复用的部分 | 借鉴的关键机制 |
|---|---|---|
| 几何算法内核 | 沿用并核验 GeomPredicates、Delaunay2D、约束恢复、事务及邻接；补必要的物理度量运算 | 稳健方向/空圆判断、局部空腔插点与合法化 |
| 边界与尺寸 | 自有共享边注册、累计长度积分、尺寸查询和缓存 | 按累计 `∫|C'(t)|/h(t) dt` 布边界点；统一尺寸来源和渐变 |
| 参考前沿生成器 | 独立生成策略，使用自有网格结构与 CAD 接口；旧生成器只作基线 | Gmsh Algorithm 6 的活动规则、优先级、候选位置、空腔验收和局部更新 |
| 曲面适配 | 现有 CAD 接口外增加所需的度量、周期分支、候选修正能力 | UV 度量生成配合物理曲面修正，处理缝、极点和非线性参数 |
| 跨面分区 | 复用平面/圆柱公共 chart；之后开发一般光滑曲面的局部图表与原面支撑 | compound 的跨分割思想及可参数化分区；真实特征仍是约束 |
| 精度反馈与优化 | 原 CAD 支撑、独立审计、局部区域重生成、有限翻边/移动 | 用局部尺寸反馈约束生成；尽量让生成阶段直接形成良好布局 |

自有谓词必须覆盖共线、近退化、坐标尺度悬殊和非法输入。符号不可靠时采用可验证的稳健求值策略，不用统一增大 epsilon 猜测方向。可复用已有正确内核，不要求全部推倒重写。

参考策略不携带旧生成器的全部补救轮次。产品精度不合格时，优先反馈局部尺寸并重新生成受影响区域；局部必须分边时同步共享边及邻面，并重新检查形状和拓扑。最终的真实特征、几何和接口验收保留。

## 跨光滑分割与可加入的改进

Gmsh compound 的流程包含原面预网格、组合离散曲面、分片线性参数化和重网格。借鉴这一思路需要额外工作，并非删除 CAD 共享边即可获得公共 UV。任意球面或有孔曲面也不能强行放入一个无奇点图表。

本项目可以在可靠参考生成器基础上增加三项改进：

1. **真实 CAD 支撑的跨面图表**：图表用于布点，每个网格点和三角仍可追踪原裁剪面；投影、偏差及原面覆盖始终针对原 CAD。界面语义由调用方输入。
2. **精度约束的局部尺寸反馈**：把超差区域转成局部尺寸需求，控制渐变并局部重生成，减少后续反复切碎良好布局。原“相同 UV 重心对应点偏差”是参数相关代理量，真实面片到 CAD 距离需独立统计；若调整验收含义，必须单独评审并保留原始对照。
3. **可追踪的增量更新与缓存**：只重算受影响邻域，区分候选失败原因、CAD 查询与拓扑耗时，保留确定性和失败回滚。

这些是拟议的工程改进，尚无性能/质量收益证明，也不宣称理论创新。每项独立开关、单独对照，测不到收益则不加入默认策略。

## 实施顺序与退出条件

### 第一阶段：先证明单面参考生成器

固定源码和可执行参考版本均为 Gmsh 4.15.2，消除既有 Python 对照 4.13.1 与研究源码版本不一致。对照分两层：算法级向自有生成器导入相同边界节点与受控尺寸函数；完整流程级比较各自边界采样，并记录实际节点和尺寸传播差异。

先做平面、孔洞平面、圆柱、球面裁剪片及同一物理面的非线性 UV 参数反例。逐项核对活动边、尺寸来源、候选位置和拒绝原因；分别保存生成出口和优化后结果。这一阶段不叠加跨面图表或产品创新。

建议验收门槛：规则自由内部区域三个角均为 50°–70° 的比例与匹配条件 Gmsh 相差不超过 5 个百分点，并同时检查 P5 最小角、P5 形状 q、片数和几何误差。这是待评审的目标，不是当前结果；不同网格不要求逐三角一致。若仍明显落后，停在规则差异定位，不继续堆后处理。

### 第二阶段：加入 CAD 产品约束

接入曲率/几何精度、周期缝、极点、窄域及共享边。对比 Gmsh 时报告实际限制差异：`MeshSizeMax` 是尺寸场上界，不能直接当成本项目“每条边硬上限”。将生成和精度验收分别计时，分析为了满足额外要求付出的成本。

### 第三阶段：跨光滑分割

从已有公共解析 chart 扩展到一般光滑曲面可参数化分区。对照同一实体的分割/未分割几何，验证跨边布局、水密、真实特征、原 CAD 支撑及归档。无法安全建图时明确保留分割，报告原因，不静默宣称跨面支持。

### 第四阶段：原模型验收，再决定创新

在 phone、凹球上比较旧生成器、自有参考生成器及 Gmsh。报告全局/自由内部/边界窄域的形状分布，原 CAD 双向采样误差，共享边、接口、片数、失败和耗时。统一版本、输入及实际参数，串行三轮取中位数，并区分核心生成与 CAD 审计。有限采样不等于全局误差证明。

达到参考效果后，再逐项测试上述改进。整模型仍无改善、错误增多或预算耗尽时回到差异证据；不取消必要检查来声称提速，不自动切换生产默认。
