# 表面三角网格尺寸入口修正方案

状态：用户已确认；Dialog、两个生成入口及显式最大尺寸已实现并验证。结果见 `../plans/2026-10-02-mesh-settings-dialog-results.md`，下文的旧状态描述为方案提出时的排查记录。

## Dialog 布局与交互（用户最新方向）

- 移除右侧网格参数 Dock，模型属性 Dock 继续原用途。
- 顶部「几何」功能区的「网格生成」组提供「三角面片」「四面体网格」两个明确入口，点击后打开参数 Dialog，不直接启动生成。
- 使用一个 `MeshSettingsDialog`，两页分别为「三角面片」「四面体」；对应入口自动选中对应页，两页参数独立，不相互覆写。
- 顶部显示当前模型名和当前类型。三角页基础项为最小尺寸、最大尺寸、最大几何偏差、最大法向变化角；高级设置折叠，开放实际有算法实现的质量/渐变/预算项。局部尺寸当前未完成，不显示可操作的占位表格。
- 四面体页保持当前真实生成链路，仅开放已被引擎消费的设置。未实现的 HXT、T10 或其他选项需核对消费点后隐藏或禁用注明，不误称可用。
- 底部「恢复默认」「取消」「生成三角面片／生成四面体」；默认值按当前模型与当前页恢复。取消/关闭丢弃本次草稿且不启动生成。生成先验证参数，成功后提交当前页参数、关闭 Dialog，再启动现有后台任务。
- 网格生成期间在主窗口显示忙状态和表面生成取消入口；关闭参数 Dialog 与取消算法工作使用不同操作，不相混淆。
- 原「网格参数设置」菜单如保留，则打开同一个 Dialog；不再唤起右侧 Dock。两类参数随工程保存/新窗口重开恢复。

### 匹配现有 UI 的依据

沿用 `resources/theme/light.qss`：浅灰底 `#F5F6F7`、白色输入框、灰色描边、深茄紫强调色 `#583266`、Microsoft YaHei UI 字体，继承现有分组/数值控件/主按钮样式。标题栏沿用 `ModelTransformDialog::showEvent` 的延迟 `MeshChrome::styleTitleBar`，不另造主题或新字体。

对话框初始约 600×520（逻辑像素）、可调整大小，内容较长时内部滚动；基础表单标签和输入框保持足够宽度，不能出现原窄 Dock 截断参数名的问题。高级项展开时保留底部按钮可见。使用现有主题做实际 GUI 图像检查，而不是只测未加载主题的测试窗口。

## 已确认的不一致

当前面板显示「目标边长」「最小目标尺寸」「表面偏差」「最大法向变化角」。前两项分别传入 `SurfaceCriteria::targetSize/minSize`；没有 `maxSize` 字段或独立最大尺寸控件。

核心以 targetSize 作为基础尺寸和尺寸场上限，但面内长边判定允许 `h × 1.05`；因此不能把现有目标边长直接改名成最大单元尺寸。minSize 已经参与尺寸场夹取及常规质量细化下限，几何误差、窄区、尖角、极点和原 CAD 小特征可能突破它并诊断，符合先前批准的软下限约定。

表面入口复用原四面体面板，导致 T4/T10、3D 算法、优化阈值和未接入的局部/共形选项同时呈现。它们不能被误认为自研表面入口的有效参数。

## 建议的明确入口

表面和四面体使用上述 Dialog 的独立页面；两种生成按钮对应各自参数。

| 表面控件 | 算法语义 |
|---|---|
| 最小单元尺寸（模型单位） | 三维边长衡量的常规细化下限。保留原有几何/特征例外，提示并定位冲突；不承诺每条边都不小于它 |
| 最大单元尺寸（模型单位） | 三维三角边长的独立上限。所有输出三角形都需复核；只允许明确的浮点比较容差，不再使用旧 5% 余量放行该上限 |
| 最大几何偏差（模型单位） | 保持原有限采样判据，不称全局误差界 |
| 最大法向变化角（°） | 保持原曲面采样法向变化判据 |

尺寸定义为三角形的三维边长，不使用面积、外接圆直径或 UV 长度代替。最大值必须正且有限；最小值不得大于最大值；非法输入在运行前显示原因。自动初值仍由 CAD 包围盒对角线的 2.5% 给出最大尺寸，最小及偏差初值为最大值的 10%。

内部基础目标取最大尺寸，再由已有尺寸场及曲率/偏差条件局部收紧。首轮不再增加第三个「目标边长」控件。质量半径边比、边界尺寸渐变及预算放入折叠的高级设置。

## 数据流与兼容

- `MeshSettingsDialog`（新增）：独立表面/四面体页、草稿/校验、主题控件和按钮；替换右侧参数面板的用户入口。原 `MeshSettingsPanel` 的有效读取/回填行为迁入对话框或独立参数状态，不把旧混合面板直接塞入 Dialog。
- `SurfaceCriteria`：新增独立 maxSize；targetSize 保留已有调用兼容。旧调用 maxSize=0 时仍按旧规则；界面新生成明确填写 maxSize，实际启用上限。
- `CadSurfaceMesher`：在共享棱采样、面内待细化评分、边界分裂条件及最终输出验收中统一应用最大尺寸；所有修复/合法化后仍核对，超预算明确失败。
- `MainWindow/SurfaceMeshEngine`：实际传递并记录 min/max/deviation/angle，生成完成不修改用户数值。
- `MainWindow`：参数状态独立于 Dialog 的对象寿命；两个 Ribbon 入口、移除旧 Dock 引用/切换菜单、状态和取消、保存/恢复共同调整；兼容旧布局设置而不重新恢复参数 Dock。
- `ProjectArchive`：保存独立 maxSize、回填独立表面控件。旧工程没有该字段时保留原 targetSize/5% 语义并明确显示迁移值，不能悄悄收紧已经保存的旧要求；用户改参数再生成采用新上限。
- CLI 及基准清单：增加可选 max 参数，记录实际生效值；旧基准和旧参数行为不变，不把旧性能记录当作新上限的结果。

minSize 仍是软下限。若未来要所有边均处于硬区间，需要独立设计短边处理/合并以及不可满足模型的拒绝策略；本轮不隐式加入该行为。

## 验证与完成标准

1. 用最小尺寸大于最大尺寸、非有限值等验证拒绝路径。
2. 平面/曲面及共享棱用例验证显式 maxSize 生效，包含原 5% 余量范围内仍必须细化的反例。
3. 对尺寸场超过上限、minSize 特征冲突、翻边后重新超长和预算不足进行检查；成功网格不得违反显式最大尺寸。
4. 工程保存/重开检查独立 min/max 字段及旧工程兼容；四面体原参数不被表面控件污染。
5. 实际 Qt 控件输入不同 min/max，点击真实按钮，核对传入值、输出最长边及保存恢复值。
   同时检查两个 Ribbon 入口打开正确页、两页参数隔离、取消丢弃草稿、生成后台状态以及现有主题下的 Dialog 图像/缩放可读性。
6. Release 构建及既有回归，move/ball 新配置验证，不沿用旧测试结果宣布新参数通过。

不创建分支/worktree、不提交，不修改四面体生成算法；实施前保护当前已有工作区改动。
